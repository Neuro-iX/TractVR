# TractVR

## Overview
TractVR is a 3D Slicer module developed for interactive tractography cleaning and manipulation in virtual reality. It is designed to support routine use by trained professionals through immersive visualization and direct interaction with fiber bundles.

## Intended use
This module is intended for professional use in a tractography workflow, particularly when immersive interaction may facilitate visualization and manual editing tasks.

## Main features
- Visualization of tractography data in virtual reality
- Interactive manipulation and cleaning of fiber bundles
- Support for ROI-based interaction
- Integration within a 3D Slicer workflow

## Repository context
This repository contains the operational VR module intended for routine use, independently from the experimental user study repositories.
